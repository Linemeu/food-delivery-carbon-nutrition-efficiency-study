# Figure plotting

Concise Python-style code for the main and supplementary figures in the online food delivery study. Panel order follows the current manuscript and supplementary information.

| File | Figure topic |
| --- | --- |
| `fig1_food_consumption.py` | Annual food consumption and city-level correlates |
| `fig2_food_basket_formats.py` | Food baskets, ingredient flows and product formats |
| `fig3_nutritional_profiles.py` | Dietary references, nutrient density and recipe profiles |
| `fig4_carbon_emissions.py` | Emission components and OFD–household differences |
| `fig5_carbon_nutrition_efficiency.py` | Two efficiency indices and city-level associations |
| `fig6_future_scenarios.py` | Order growth, mitigation and nutrition pathways |
| `fig_s1_classifier_validation.py` | Internal product-format classifier validation |
